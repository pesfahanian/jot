# Banned Vocabulary

Direct substitution lists. T1-02 (banned vocabulary), T1-12 (phrasal verbs), and T1b-03 (nominalization) check against this file.

## AI-tell vocabulary → plain replacement

| Banned | Use instead |
|---|---|
| delve | look at / cover |
| showcase | show |
| underscores | shows / confirms |
| noteworthy | (usually cut entirely) |
| pivotal | key / central |
| realm | area / field |
| tapestry | (cut, or name the actual thing) |
| multifaceted | (name the specific facets instead) |
| meticulous | careful / precise |
| intricate | complex / detailed |
| commendable | (cut, or state the specific result) |

## Marketing adjectives → cut or replace with a fact

| Banned | Use instead |
|---|---|
| seamless | (state what actually happens at the boundary) |
| robust | (state the failure mode it survives) |
| powerful | (state the number or capability) |
| cutting-edge | (cut) |
| best-in-class | (cut, or cite the comparison) |
| innovative | (cut) |

## Inflated verbs → plain verb

This is a genuine vocabulary substitution, distinct from the elegant-variation issue (T1b-02). These have real plain equivalents with no loss of meaning — the fix here is a straight swap, not a restructure.

| Banned | Use instead |
|---|---|
| utilize | use |
| facilitate | help / enable |
| commence | start |
| leverage | use |
| demonstrate | show |
| implement | build / do |

## Phrasal verbs → single verb

| Banned | Use instead |
|---|---|
| spin up | start |
| reach out | contact |
| dive into | examine / cover |
| kick off | start |
| take off (a part) | remove |

## Nominalization → verb form (T1b-03)

Covers the common cases; a form not listed here falls back to the shared LLM call per checks.md.

| Nominalized (light verb + noun) | Verb form |
|---|---|
| perform/conduct an analysis | analyze |
| make a decision | decide |
| provide assistance | assist / help |
| conduct an investigation | investigate |
| carry out an implementation | implement |
| perform a review | review |
| make an assessment | assess |
| provide clarification | clarify |
| conduct a discussion | discuss |
| make a recommendation | recommend |
